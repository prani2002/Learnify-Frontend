# Learnify LMS Demo

## What is this app

Learnify is a learning management system (LMS) web application with a public landing page, a login screen, and separate dashboards for learners and administrators.

## Purpose

The app was built as a working sample for hackathon preparation, to demonstrate a polished LMS front end and to give a realistic application to exercise logging and error handling.

## Disclaimer

All content in this app is dummy data, including courses, users, learners, statistics, and analytics. It was made for hackathon purposes and is not an enterprise product.

## How to run

Requires Node.js 20 or later.

```
npm install
npm run dev
```

Open http://localhost:3000.

Other scripts: `npm run build`, `npm run start`, `npm run lint`, `npm run typecheck`.

## Tech stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
